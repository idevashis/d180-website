# D180 Website — Final Static Build

This package preserves the existing D180 visual identity and adds the requested legal/contact layer.

## Upload structure
Upload the contents of this folder directly to the root of your GitHub repository. Keep the `assets` folder exactly as shown.

```
index.html
experience.html
speakers.html
speaker.html
about.html
partner.html
pass.html
privacy-policy.html
terms.html
copyright.html
disclaimer.html
cookies.html
styles.css
script.js
assets/
  founder.png
  favicon.png
  apple-touch-icon.png
  d180-logo.png
```

## Contact form
The single editable contact-form setting is in `script.js`:

`const CONTACT_FORM_URL = "https://forms.gle/Xz2CtqApPugpg7gf8";`

If the URL ever changes, replace only that value. Contact Us links automatically open in a new tab. If the value is blank, the links stay non-functional rather than creating a broken external URL.
